# 快速启动指南

## 🚀 5分钟启动系统

### 1. 安装依赖（首次运行）

```bash
cd backend
pip install fastapi uvicorn pydantic
```

### 2. 启动服务器

```bash
cd backend
python app.py
```

你会看到：
```
INFO:     Uvicorn running on http://127.0.0.1:8000
```

### 3. 打开浏览器

访问：`http://localhost:8000`

## ✅ 验证系统正常工作

### 方法1: Web界面测试

1. 打开 `http://localhost:8000`
2. 点击"生成K文件"（使用默认值）
3. 如果成功下载文件，系统正常！

### 方法2: 后端测试

```bash
cd backend
python -c "from k_engine import KFileEngine; print('OK - Backend works!')"
```

如果输出 `OK - Backend works!`，后端正常！

## 🔍 生成的文件在哪里？

- **下载到浏览器**: 浏览器默认下载文件夹
- **服务器副本**: `generated/` 目录
- **元数据**: 同名 `_metadata.json` 文件

例如：
```
generated/
├── bullet_sim_20251107_143022_v2500_by1500_ty800_fs0.20_fd0.15_t20.k
└── bullet_sim_20251107_143022_v2500_by1500_ty800_fs0.20_fd0.15_t20_metadata.json
```

## 📐 单位系统速查

| 物理量 | 物理单位 | K文件单位 | 转换公式 | 示例 |
|--------|---------|----------|---------|------|
| 速度 | m/s | 10 km/s | K值 × 10000 | 0.16 → 1600 m/s |
| 应力 | MPa | 0.01 GPa | K值 × 100000 | 0.01 → 1000 MPa |
| 时间 | µs | 0.1 µs | K值 × 0.1 | 300.0 → 30.0 µs |

⚠️ **注意**: 应力转换是 **×100000** (不是×1000)

## ⚠️ 常见问题快速解决

### ❌ 浏览器打不开页面

**原因**: 服务器未启动或端口被占用

**解决**:
```bash
# 检查是否已启动
cd backend
python app.py
```

### ❌ LS-DYNA报错 "Error 20001 line 6"

**原因**: UTF-8 BOM编码问题（旧版本bug）

**解决**: 确保使用 v1.0.1 或更高版本，系统会自动生成无BOM文件

### ❌ 参数验证失败

**原因**: 参数超出合理范围

**解决**: 检查错误提示，调整到推荐范围内
