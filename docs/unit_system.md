# LS-DYNA K文件单位系统说明

## 概述

本项目使用的 LS-DYNA K 文件采用**非标准单位系统**，需要特别注意单位转换关系。

---

## 单位系统定义

| 物理量 | K文件单位 | 显示单位 | 转换关系 |
|--------|----------|---------|----------|
| **质量** | g (克) | g | K值 = 物理值 |
| **长度** | mm (毫米) | mm | K值 = 物理值 |
| **时间** | 0.1 µs | µs (微秒) | K值 × 0.1 = µs |
| **密度** | g/cm³ | g/cm³ | K值 = 物理值 |
| **应力/弹性模量** | 0.01 GPa | MPa | K值 × 1000 = MPa |
| **应力/弹性模量** | 0.01 GPa | GPa | K值 × 100 = GPa |
| **速度** | 10 km/s | m/s | K值 × 10000 = m/s |

---

## 详细转换说明

### 1. 速度转换

**K文件单位**: 10 km/s
**显示单位**: m/s

```
K文件值 → 物理值：速度(m/s) = K值 × 10000
物理值 → K文件值：K值 = 速度(m/s) / 10000

示例：
K值 0.16 → 0.16 × 10000 = 1600 m/s ✓
1600 m/s → 1600 / 10000 = 0.16 ✓
```

**推导过程**：
```
K值单位 = mm / (0.1 µs)
        = mm / (0.1 × 10⁻⁶ s)
        = 10⁷ mm/s
        = 10⁴ m/s
        = 10 km/s
```

---

### 2. 应力/强度转换

**K文件单位**: 0.01 GPa = 10 MPa
**显示单位**: MPa 或 GPa

```
K文件值 → MPa：应力(MPa) = K值 × 1000
K文件值 → GPa：应力(GPa) = K值 × 100

MPa → K文件值：K值 = 应力(MPa) / 1000
GPa → K文件值：K值 = 应力(GPa) / 100

示例：
K值 0.01 → 0.01 × 1000 = 10 MPa (或 1 GPa) ✓
1000 MPa → 1000 / 1000 = 1.0 (K值) ✓
```

---

### 3. 时间转换

**K文件单位**: 0.1 µs
**显示单位**: µs (微秒)

```
K文件值 → 微秒：时间(µs) = K值 × 0.1
微秒 → K文件值：K值 = 时间(µs) / 0.1

示例：
K值 300.0 → 300.0 × 0.1 = 30 µs ✓
30 µs → 30 / 0.1 = 300.0 (K值) ✓
```

---

### 4. 密度转换

**K文件单位**: g/cm³
**显示单位**: g/cm³

```
无需转换，直接使用

示例：
K值 7.86 = 7.86 g/cm³ = 7860 kg/m³
```

## 为什么使用这种单位系统？

1. **数值范围优化**: 保持参数值在合理范围（避免过大或过小的数字）
2. **数值稳定性**: 减少浮点运算误差
3. **历史兼容**: 保持与现有模型的兼容性

---

## 注意事项

1. ⚠️ **严格遵守转换公式**: 单位错误会导致完全错误的仿真结果
2. ⚠️ **K文件格式不可破坏**: 必须保持固定列宽格式
3. ⚠️ **验证转换**: 修改参数后应检查物理意义是否合理

## 快速参考

```python
# Python 转换代码示例
def velocity_to_k(v_ms):
    """m/s → K值"""
    return v_ms / 10000.0

def stress_to_k(s_mpa):
    """MPa → K值"""
    return s_mpa / 1000.0

def time_to_k(t_us):
    """µs → K值"""
    return t_us / 0.1
```
