# LS-DYNA 参数指南

## 6个核心参数详细说明

---

## 1. 弹丸初速度 (velocity_z)

**物理意义**: 弹丸撞击靶板时的初始速度

**参数范围**: 500 - 3000 m/s

**K文件位置**: 行 239

**推荐值**:

| 场景 | 速度 (m/s) | 说明 |
|------|-----------|------|
| 低速冲击 | 500-1000 | 用于抗冲击研究，靶板主要发生塑性变形 |
| 中速穿甲 | 1000-2000 | 典型穿甲弹速度，是最常见的研究场景 |
| 高速穿甲 | 2000-2800 | 超高速穿甲，可能出现流体动力学效应 |
| 超高速冲击 | 2800-3000 | 接近极限速度，数值计算可能不稳定 |

**影响因素**:
- 🎯 **穿透性能**: 速度越高，穿透能力越强
- ⏱️ **仿真时间**: 高速冲击过程更短，建议减少终止时间
- 💥 **破坏模式**: 低速以塑性变形为主，高速可能出现绝热剪切、熔化等

**注意事项**:
- 速度超过 3000 m/s 时，材料模型可能不再适用
- 高速冲击需要更小的时间步长，计算成本增加

---

## 2. 弹丸屈服强度 (bullet_yield_stress)

**物理意义**: 弹丸材料开始发生塑性变形的应力

**参数范围**: 500 - 2000 MPa

**K文件位置**: 行 211

**推荐值**:

| 材料类型 | 屈服强度 (MPa) | 典型材料 |
|---------|---------------|---------|
| 软钢弹丸 | 500-700 | Q235钢 |
| 普通钢弹丸 | 800-1000 | 45号钢 |
| 硬化钢弹丸 | 1200-1500 | 40Cr淬火钢 |
| 特种钢弹丸 | 1500-2000 | 高强度合金钢、钨合金 |

**影响因素**:
- 🔸 **弹丸变形**: 屈服强度低，弹丸易变形或破碎
- 🎯 **穿透效率**: 高强度弹丸保持形状，穿透效率高
- ⚡ **能量耗散**: 弹丸变形会消耗动能，降低穿透深度

**与靶板强度的关系**:
```
bullet_yield / target_yield > 1.5  → 弹丸保持形状，有效穿透
bullet_yield / target_yield ≈ 1.0  → 弹丸和靶板共同变形
bullet_yield / target_yield < 0.7  → 弹丸可能严重变形或破碎
```

---

## 3. 靶板屈服强度 (target_yield_stress)

**物理意义**: 靶板材料开始发生塑性变形的应力

**参数范围**: 200 - 1200 MPa

**K文件位置**: 行 216

**推荐值**:

| 防护等级 | 屈服强度 (MPa) | 典型材料 |
|---------|---------------|---------|
| 软钢靶板 | 200-400 | 低碳钢 |
| 中碳钢靶板 | 400-700 | 45号钢 |
| 装甲钢靶板 | 800-1000 | 装甲钢、高强度钢 |
| 高强度装甲 | 1000-1200 | 特种装甲材料 |

**影响因素**:
- 🛡️ **抗穿透能力**: 屈服强度高，抗穿透能力强
- 💥 **破坏模式**: 低强度靶板主要发生冲塞破坏，高强度靶板可能出现花瓣破坏
- 📐 **厚度需求**: 高强度材料可以用较薄的厚度达到相同防护

**设计建议**:
- 研究穿透性能：使用中等强度靶板 (600-800 MPa)
- 研究防护性能：使用高强度靶板 (>1000 MPa)
- 对比研究：设置不同强度进行参数化分析

---

## 4. 静摩擦系数 (friction_static)

**物理意义**: 接触界面静止时的摩擦阻力

**参数范围**: 0.0 - 0.8

**K文件位置**: 行 192

**推荐值**:

| 接触状态 | 摩擦系数 | 说明 |
|---------|---------|------|
| 无摩擦（理想） | 0.0 | 理论分析，忽略摩擦影响 |
| 润滑表面 | 0.05-0.10 | 油润滑、水润滑 |
| 钢-钢干摩擦 | 0.15-0.30 | 最常见的设置 |
| 粗糙表面 | 0.40-0.60 | 表面未处理、氧化层 |
| 极粗糙 | 0.60-0.80 | 特殊表面处理 |

**影响因素**:
- 🔥 **能量耗散**: 摩擦增加能量损失，降低穿透深度
- 📐 **轨迹偏转**: 摩擦力会导致弹丸轨迹偏转
- 🌡️ **温度升高**: 摩擦生热，影响材料性能

**典型设置**:
```
钢弹丸 + 钢靶板 (干燥)：fs = 0.25
钢弹丸 + 铝靶板：fs = 0.20
有润滑剂：fs = 0.05-0.10
```

---

## 5. 动摩擦系数 (friction_dynamic)

**物理意义**: 接触界面滑动时的摩擦阻力

**参数范围**: 0.0 - 0.6

**K文件位置**: 行 192

**推荐值**:
- 通常为静摩擦系数的 **60-80%**
- 例如：fs = 0.25 → fd = 0.15-0.20

| 静摩擦 | 动摩擦 | 说明 |
|-------|-------|------|
| 0.25 | 0.18 | 钢-钢标准设置 |
| 0.30 | 0.20 | 粗糙表面 |
| 0.15 | 0.10 | 光滑表面 |

**物理意义**:
- 静摩擦>动摩擦是符合物理规律的
- 动摩擦主要影响弹丸穿透过程中的能量耗散速率

**约束关系**:
```
必须满足：friction_dynamic ≤ friction_static
推荐比例：friction_dynamic = 0.6~0.8 × friction_static
```

## 6. 仿真终止时间 (simulation_endtime)

**物理意义**: 仿真计算的持续时间

**参数范围**: 10 - 100 µs

**K文件位置**: 行 28

**推荐值**:

| 速度范围 | 终止时间 (µs) | 说明 |
|---------|--------------|------|
| 高速 (>2000 m/s) | 10-20 | 穿透过程很快完成 |
| 中速 (1000-2000) | 20-40 | 标准设置 |
| 低速 (<1000) | 40-100 | 需要观察长时间响应 |

**确定方法**:

1. **基于速度估算**:
   ```
   穿透时间 ≈ 靶板厚度 / 弹丸速度

   例如：
   厚度 50 mm，速度 1600 m/s
   穿透时间 ≈ 50 mm / 1600 m/s = 31 µs

   建议设置：endtime = 1.5 × 穿透时间 ≈ 45 µs
   ```

2. **分阶段调整**:
   - 初步仿真：设置较短时间（如 20 µs）
   - 检查结果：弹丸是否完全穿透或停止
   - 调整时间：如未完成则增加时间

**计算成本**:
- 时间越长，计算量越大
- 高速冲击可以用较短时间节省成本

## 参数组合推荐

### 场景1：标准穿甲测试
```
velocity_z: 1600 m/s
bullet_yield_stress: 1000 MPa
target_yield_stress: 800 MPa
friction_static: 0.25
friction_dynamic: 0.18
simulation_endtime: 30 µs
```

### 场景2：高速穿甲

friction_static: 0.20

## 参数验证检查清单

使用系统前，请确认：

- [ ] 弹丸初速度符合研究目标
- [ ] 弹丸屈服强度 > 靶板屈服强度 × 0.7 (避免弹丸过度变形)
- [ ] 动摩擦系数 ≤ 静摩擦系数
- [ ] 仿真时间足够观察完整过程
- [ ] 参数组合物理合理（无极端值）
