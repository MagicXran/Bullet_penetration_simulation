# 仿真动画生成 - 用户指南

**版本**: 1.0
**功能**: 自动将LS-DYNA仿真结果（d3plot文件）渲染为MP4动画
**最后更新**: 2025-11-07

---

## 📋 功能概述

本系统提供**阶段2专业自动化方案**，通过后端Python程序自动调用LS-PrePost软件，将d3plot仿真结果渲染为高质量MP4动画。

**核心优势**：
- ⚡ **全自动渲染** - 无需手动操作LS-PrePost
- 🎨 **自定义视角** - 支持7种相机视角
- 📊 **多种云图变量** - 应力、应变、位移、速度等
- 🔄 **异步任务队列** - 后台处理，不阻塞前端
- 🎬 **专业质量** - 使用LS-PrePost原生渲染引擎

## 🎯 前置条件

### 1. 软件要求

| 软件 | 版本要求 | 说明 |
|------|----------|------|
| LS-PrePost | 4.0+ | 必需，用于渲染动画 |
| Python | 3.8+ | 后端服务 |
| LS-DYNA | 任意版本 | 生成d3plot文件 |

### 2. 仿真流程

```
K文件 → LS-DYNA求解器 → d3plot文件 → LS-PrePost → MP4动画
        ↑ 本系统生成           ↑ 用户运行      ↑ 本系统自动调用
```

**重要**：动画生成功能需要用户先运行LS-DYNA仿真，产生d3plot文件。

## ⚙️ 配置步骤

### 步骤1: 安装LS-PrePost

1. 从LSTC官网下载LS-PrePost：https://lsdyna.ansys.com/
2. 安装到默认位置，或记录安装路径

**Windows典型路径**：
```
C:\Program Files\LSTC\LS-PrePost 4.9\lsprepost4.9_x64.exe
```

**Linux典型路径**：
```
/usr/local/lsprepost/lspp
```

### 步骤2: 配置系统

编辑文件：`backend/config.json`

```json
{
  "lsprepost_executable": "C:\\Program Files\\LSTC\\LS-PrePost 4.9\\lsprepost4.9_x64.exe",
  "animation_output_dir": "generated/animations",
  "default_resolution": [1920, 1080],
  "default_fps": 30
}
```

**注意事项**：
- Windows路径使用双反斜杠 `\\` 或单斜杠 `/`
- 确保路径指向实际的LS-PrePost可执行文件
- 如果文件不存在，复制 `config.json` 模板并修改

### 步骤3: 验证配置

启动后端服务：
```bash
cd backend
python app.py
```

如果配置正确，会看到：
```
[INFO] 动画生成器初始化成功
```

如果看到警告：
```
[WARNING] 动画生成器初始化失败: LS-PrePost可执行文件不存在
```
说明配置路径有误，请检查 `config.json`。

## 🚀 使用流程

### 完整工作流

```
┌────────────────┐
│ 1. 生成K文件   │  ← 使用Web界面配置参数，生成K文件
└────────┬───────┘
         ↓
┌────────────────┐
│ 2. 运行仿真    │  ← 在LS-DYNA中运行K文件，生成d3plot
└────────┬───────┘
         ↓
┌────────────────┐
│ 3. 生成动画    │  ← 使用本系统自动渲染动画
└────────┬───────┘
         ↓
┌────────────────┐
│ 4. 播放/下载   │  ← 在线播放或下载MP4文件
└────────────────┘
```

### 详细步骤

#### 第1步：运行LS-DYNA仿真

假设你生成了K文件：`bullet_sim_20251107_143022.k`

1. 在LS-DYNA中运行该文件
2. 等待求解完成，产生d3plot文件
3. 记录d3plot文件的完整路径

**d3plot文件示例路径**：
```
D:\Simulations\bullet_sim_20251107_143022\d3plot
```

#### 第2步：创建动画任务

1. 打开Web界面：`http://localhost:8000`
2. 滚动到"仿真动画生成"部分
3. 填写表单：

| 字段 | 说明 | 示例 |
|------|------|------|
| d3plot文件路径 | 服务器可访问的绝对路径 | `D:\Simulations\bullet_sim\d3plot` |
| 相机视角 | 7种预设视角 | 等角视图 (Isometric) |
| 云图变量 | 显示的物理量 | 应力 (Stress) |
| 视频分辨率 | 输出视频分辨率 | 1920x1080 (Full HD) |
| 帧率 | 视频帧率 | 30 fps |

4. 点击"开始生成动画"

#### 第3步：监控任务进度

- 任务创建后，前端会显示任务卡片
- 状态自动更新（每3秒轮询一次）
- 查看进度条了解渲染进度

**任务状态**：
- 🟡 **等待中 (pending)** - 任务已创建，等待处理
- 🔵 **处理中 (processing)** - 正在渲染动画
- 🟢 **已完成 (completed)** - 动画生成成功
- 🔴 **失败 (failed)** - 渲染失败，查看错误信息

#### 第4步：播放或下载动画

任务完成后，任务卡片会显示两个按钮：
- **播放** - 在网页中直接播放MP4动画
- **下载** - 下载MP4文件到本地

## 🎨 参数说明

### 相机视角

| 视角 | 英文名 | 说明 |
|------|--------|------|
| 等角视图 | Isometric | 默认视角，适合整体观察 |
| 正视图 | Front | 从前方观察 |
| 后视图 | Back | 从后方观察 |
| 俯视图 | Top | 从上方俯视 |
| 仰视图 | Bottom | 从下方仰视 |
| 左视图 | Left | 从左侧观察 |
| 右视图 | Right | 从右侧观察 |

**推荐**：首次使用选择"等角视图"，可以看到完整的穿甲过程。

### 云图变量

| 变量 | 英文名 | 说明 | 适用场景 |
|------|--------|------|----------|
| 应力 | Stress | 材料的应力分布 | 分析材料破坏、塑性变形 |
| 应变 | Strain | 材料的应变分布 | 研究变形程度 |
| 位移 | Displacement | 节点位移大小 | 观察整体运动轨迹 |
| 速度 | Velocity | 节点速度大小 | 分析动态响应 |
| 加速度 | Acceleration | 节点加速度大小 | 研究冲击载荷 |
| 塑性应变 | Plastic Strain | 塑性应变分布 | 分析永久变形区域 |

**推荐**：穿甲仿真通常使用"应力 (Stress)"查看材料的受力情况。

### 视频参数

| 参数 | 可选值 | 推荐 | 说明 |
|------|--------|------|------|
| 分辨率 | 1280x720, 1920x1080, 3840x2160 | 1920x1080 | Full HD足够，4K文件较大 |
| 帧率 | 24, 30, 60 fps | 30 fps | 平衡流畅度和文件大小 |

## ⚠️ 常见问题

### Q1: 创建任务时提示"d3plot文件不存在"

**原因**：
- 路径错误
- 服务器无法访问该路径（权限问题）
- d3plot文件尚未生成

**解决**：
1. 检查路径是否正确（绝对路径，不是相对路径）
2. 确认LS-DYNA仿真已完成，d3plot文件确实存在
3. 确保服务器有权限访问该目录

### Q2: 任务状态一直是"处理中"，但很久没完成

**可能原因**：
- d3plot文件很大，渲染需要较长时间
- LS-PrePost进程卡住
- 内存不足

**解决**：
1. 耐心等待（大模型可能需要5-10分钟）
2. 检查服务器CPU和内存使用情况
3. 查看后端日志：`backend/app.py` 的控制台输出

### Q3: 任务失败，错误信息"LS-PrePost执行失败"

**可能原因**：
- d3plot文件损坏
- LS-PrePost配置错误
- CFILE脚本语法错误

**排查步骤**：
1. 手动打开LS-PrePost，加载该d3plot文件，确认文件有效
2. 检查 `generated/animations/cfile_*.cfile` 文件内容是否正确
3. 查看后端日志中的详细错误信息（stdout/stderr）

### Q4: 动画质量不理想，如何调整？

**方法1：提高分辨率**
- 从1920x1080升级到3840x2160 (4K)
- 缺点：文件更大，渲染时间更长

**方法2：更换视角**
- 尝试不同的相机视角
- 选择最能展示穿甲过程的角度

**方法3：更换云图变量**
- 如果应力云图不清晰，尝试位移或速度

### Q5: 可以批量生成多个视角的动画吗？

**当前版本**：需要手动创建多个任务

**计划功能**（未来版本）：
- 多视角并行渲染
- 视频拼接（画中画）

**临时方案**：
创建多个任务，分别指定不同视角：
1. 任务1：等角视图 + 应力
2. 任务2：正视图 + 应力
3. 任务3：俯视图 + 位移

## 🔧 高级功能

### 查看CFILE脚本

系统生成的CFILE脚本存储在：
```
generated/animations/cfile_{任务ID}.cfile
```

示例内容：
```cfile
$# LS-PrePost自动化脚本 - 动画生成
*OPEN "D:\\Simulations\\bullet_sim\\d3plot"
*FRINGE 1 1
*VIEW ISOMETRIC
*SCALE AUTO
*PALETTE RAINBOW
*OUTPUT MOVIE "D:\\...\\animation.mp4" 1920 1080 30
*ANIMATE
*QUIT
```

你可以手动修改此文件，然后在LS-PrePost中运行：
```bash
lsprepost.exe c=cfile_{任务ID}.cfile
```

## 💡 最佳实践

### 1. 规划仿真输出

在运行LS-DYNA时，合理设置d3plot输出频率：
- 太密集：文件大，渲染慢
- 太稀疏：动画不流畅

**推荐**：穿甲过程持续30µs，输出100-200个时间步即可。

### 2. 选择合适的分辨率

- 🎯 **预览**：1280x720 (快速生成，预览效果)
- ✅ **标准**：1920x1080 (推荐，平衡质量和速度)
- 🎨 **发表**：3840x2160 (论文插图，高质量)

### 3. 组织d3plot文件

建议目录结构：
```
Simulations/
├── case1_v1600_by1000_ty800/
│   ├── bullet_sim.k
│   ├── d3plot
│   ├── animation_iso.mp4
│   └── animation_front.mp4
├── case2_v2500_by1500_ty800/
│   ├── bullet_sim.k
│   ├── d3plot
│   └── ...
```

### 4. 定期清理文件

动画文件会占用大量磁盘空间，建议：
- 完成分析后，下载需要的动画
- 定期清理 `generated/animations/` 目录
- 保留重要案例的动画文件

### 案例2：多视角对比研究

**场景**：需要从不同角度分析穿甲过程

**任务创建**：
1. 任务1：等角视图 + 应力
2. 任务2：正视图 + 应力
3. 任务3：俯视图 + 位移

**后期处理**：
使用视频编辑软件（如FFmpeg）拼接三个视角：
```bash
ffmpeg -i animation1.mp4 -i animation2.mp4 -i animation3.mp4 \
  -filter_complex "[0:v][1:v][2:v]hstack=inputs=3[v]" \
  -map "[v]" output_combined.mp4
```
